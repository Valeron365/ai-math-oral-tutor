# AI Math Oral Tutor & Exam Evaluator

Интеллектуальный AI-сервис для подготовки школьников к теоретическим зачетам по геометрии и алгебре, устной части теории ОГЭ по математике, а также для автоматизированной проверки устных ответов.

## Проблема и цель проекта
В школьной программе по математике (особенно в геометрии и при подготовке к ОГЭ) критически важно точное знание определений, аксиом, теорем и их доказательств. Однако в рамках урока учитель физически не успевает провести индивидуальный устный опрос каждого ученика и подробно разобрать логические неточности в формулировках.

**Цель проекта** — создать отказоустойчивую AI-систему, работающую в двух режимах:
1. **Режим подготовки (AI-тренажер):** интерактивная отработка теории по геометрии, алгебре и ОГЭ с наводящими вопросами и подсказками по базе знаний (RAG).
2. **Режим зачета (Автооценка):** объективная проверка устного или текстового ответа ученика по эталонным критериям (рубрикатору) с выявлением логических и фактических ошибок и формированием отчета для учителя.

## Архитектура системы
Система разделена на два контура для обеспечения высокой пропускной способности под нагрузкой и гибкости развития мультимодальных функций:

1. **Tutor & Evaluation Core (FastAPI + LLM + RAG + Agents):**
   - Векторная база знаний по школьной программе (определения, теоремы, свойства, типичные ловушки из теории ОГЭ).
   - Агентная маршрутизация сценариев: режим мягкого обучения с подсказками или режим строгого экзаменатора.
   - Генерация строго структурированного JSON-отчета (Pydantic): балл, верно раскрытые тезисы, критические логические ошибки (например, подмена кванторов или потеря условия теоремы), наводящий вопрос.
   - Система оценки качества (LLM-as-a-Judge) и оптимизация инференса для работы под нагрузкой.

2. **Speech & Audio Pipeline (ASR + Speech Analytics + TTS):**
   - Распознавание устных ответов учеников (Whisper / GigaAM) с адаптацией под математическую терминологию.
   - Анализ речевых характеристик (темп речи, паузы, хезитации) и опциональная озвучка вопросов экзаменатора (TTS).

## Стек технологий
- **Backend & API:** Python, FastAPI, Pydantic
- **LLM & Agents:** OpenAI-compatible API / локальные LLM (LoRA fine-tuning), RAG, Guardrails
- **Speech & Audio:** Whisper / GigaAM, аудиоаналитика, TTS
- **MLOps & Testing:** Docker, pytest, нагрузочное тестирование (Locust)
